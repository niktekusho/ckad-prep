Generate, don't type

Lesson 1 of your CKAD prep. About 15 minutes, then the diagnostic.

The exam gives you 2 hours for 15 to 20 hands-on tasks (LF exam tips). That is 6 to 8 minutes per task. Typing a manifest from memory costs most of that budget and adds indentation errors. Have kubectl write the YAML skeleton, then add only the fields it can't generate.

1. Set up your shell once

Add this to ~/.bashrc in WSL, then open a new terminal:

alias k=kubectl
source <(kubectl completion bash)
complete -o default -F __start_kubectl k
export do="--dry-run=client -o yaml"

The exam terminal already has the k alias and completion (LF exam tips). The alias and completion lines come from the kubectl quick reference, which is an allowed docs page. On exam day, type only the export do=... line.

Add this line to ~/.vimrc so a Tab in YAML becomes two spaces:

set expandtab tabstop=2 shiftwidth=2

2. The loop

k create deploy web --image=nginx:1.27 --replicas=3 $do > web.yaml
vim web.yaml          # add the fields kubectl can't generate
k apply -f web.yaml

--dry-run=client builds the object without sending it to the cluster. -o yaml prints it. For a field you can't remember, ask the API directly instead of searching:

k explain pod.spec.containers.securityContext
k explain deploy.spec.strategy.rollingUpdate

For whole blocks (probes, volumes, NetworkPolicies), copy the example from the kubernetes.io Tasks pages. The generator reference lists which command creates which object.

3. Check yourself

Which command prints a Deployment manifest without creating anything?

Which part of a Deployment can't k create deploy set from a flag?

Which command lists the fields allowed under a container's securityContext?

4. Your first win: the diagnostic

Run the 11-task diagnostic from the repo root in WSL, after kubectl config use-context docker-desktop. It covers every domain except Helm and Kustomize, with about 65 minutes of budget in total. Each task gets its own namespace, so use -n <task> or switch with k config set-context --current --namespace=<task>.

./drill run diag-01

Press Enter to check a task. Failed lines show what the cluster has now. Skip any task that stalls you for more than twice its budget. The runner logs your time and result to progress/log.csv, and ./drill stats shows pass rate and time per domain. The next session targets whatever comes out weakest.
