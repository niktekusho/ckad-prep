Custom resources

Lesson 4 of your CKAD prep. About 10 minutes, then run session-03.

1. Why it is on the exam

The curriculum lists "Discover and use resources that extend Kubernetes (CRD, Operators)" under Application Environment, Configuration and Security (CNCF curriculum). That is your slowest domain, so this is a cheap place to win points. A task gives you a CRD that already exists and asks you to find out what it offers and create an object from it.

2. The model

  • A CustomResourceDefinition (CRD) teaches the API server a new kind. Its name is <plural>.<group>.
  • A custom resource (CR) is an object of that kind. You create it like any other object, with kubectl apply.
  • An operator is a controller that watches CRs and acts on them. The exam only asks you to use CRs, so you never write one.

3. Discover, then use

kubectl get crd                                 # every CRD in the cluster
kubectl api-resources | grep -i backup          # kind, group, short name, namespaced?
kubectl explain backup.spec                     # fields and which are required
kubectl get crd backups.drill.example.com -o yaml   # full schema if explain is thin
kubectl get backups -n crd-use                  # list objects (plural, singular or short name)

Then write the object. apiVersion is <group>/<version>, kind is the CRD's kind, and spec holds the fields from explain:

apiVersion: drill.example.com/v1
kind: Backup
metadata:
  name: nightly
spec:
  schedule: "0 2 * * *"
  target: db

Check NAMESPACED in api-resources. A cluster-scoped kind ignores -n. The CRD required list is enforced, so a missing field is rejected with a clear error.

The docs page is Extend the Kubernetes API with CustomResourceDefinitions. You will not write a CRD on the exam, but its example shows every field you will meet.

4. Check yourself

You need the apiVersion for a kind you have never seen. Which command shows it fastest?

The create is rejected for a missing field. Where do you find the field list?

No operator is installed. What happens when you create a custom resource?
