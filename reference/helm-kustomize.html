Helm and Kustomize

Every helm command takes -n <ns>. Docs: helm.sh/docs/helm, kubernetes.io Kustomize.

Helm

GoalCommand
Add a repo, find a charthelm repo add b <url> · helm repo update · helm search repo b/
See settable valueshelm show values <chart>
Installhelm install <rel> <chart> --set k=v or -f vals.yaml
Find releaseshelm list -A
Values a release useshelm get values <rel>
Upgradehelm upgrade <rel> <chart> --set k=v
Revisionshelm history <rel>
Roll backhelm rollback <rel> [rev] (no rev = previous; adds a new revision)
Removehelm uninstall <rel>
Render without installinghelm template <rel> <chart> --set k=v

Kustomize overlay

resources: [../base]
namespace: prod
namePrefix: prod-
labels:
- pairs: {env: prod}       # objects only; commonLabels also edits selectors
images:
- name: nginx
  newTag: "1.27"
patches:
- patch: |-
    apiVersion: apps/v1
    kind: Deployment
    metadata: {name: web}  # base name, without prefix
    spec: {replicas: 3}
