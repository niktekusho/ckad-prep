Custom resources

Docs: kubernetes.io CRDs.

GoalCommand
List CRDskubectl get crd
Kind, group, short name, scopekubectl api-resources | grep -i <word>
Fields and required oneskubectl explain <kind>.spec
Full schemakubectl get crd <plural>.<group> -o yaml
List objectskubectl get <plural|singular|short> -n <ns>
Only nameskubectl get <kind> -o name (prefix is kind.group/)

Object skeleton

apiVersion: <group>/<version>
kind: <Kind>
metadata:
  name: x
spec:
  <fields from kubectl explain>

Cluster-scoped kinds ignore -n. An operator only reacts to objects. Without one, a CR is stored data.
